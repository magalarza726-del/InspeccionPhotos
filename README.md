# Inspeccion Photos

Aplicación Android de inspección fotográfica en Kotlin/Jetpack Compose.

Este repositorio contiene la versión **v3.3.1** del proyecto y un flujo de GitHub Actions para generar un APK instalable desde el teléfono.

La fuente del proyecto está empaquetada en `InspeccionPhotos-src.tar.xz`; el workflow la extrae automáticamente antes de compilar.
